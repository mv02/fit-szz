**Složitost algoritmu** vyjadřuje vlastnosti algoritmu *nezávisle na technických podrobnostech*. Popisuje se pomocí jednoduchých *matematických funkcí*.

## Časová složitost

**Časová složitost** algoritmů je odvozena od počtu tzv. *elementárních operací* – sčítání, násobení, porovnání, skoky atd. Udává **řádový počet provedených operací** v závislosti na *velikosti vstupu* (nejhorší případ).

**Určení časové složitosti**:

1. Zhodnotíme, *jak měřit vellkost vstupu*.
2. Určíme *maximální možný počet elementárních kroků* algoritmu provedených pro vstup o velikosti $n$.
3. Ve výsledné formuli ponecháme pouze *nejrychleji rostoucí člen*, ostatní zanedbáme.
4. *Seškrtáme multiplikativní konstanty*.

Bereme tedy v úvahu pouze to, jak časová náročnost algoritmu **roste řádově**, zanedbáváme aditivní i multiplikativní konstanty.

### Asymptotická časová složitost

**Asymptotická časová složitost** je *nejčastěji používané* hodnotící kritérium. Chování algoritmu popisuje **porovnáním s jinou funkcí**. Pro $n$ jdoucí *k nekonečnu* se chování algoritmu **blíží této funkci**.

#### Složitost Omikron

**Složitost Omikron** (*big O*) vyjadřuje **horní hranici** časového chování algoritmu.
$$f(n) \in O(g(n)) \Longleftrightarrow \exists c \in \mathbb > 0, n_0 \in \mathbb{N}: \forall n \geq n_0, f(n) \leq c \cdot g(n)$$

Funkce $f(n)$ je **rostoucí maximálně tak rychle** jako funkce $g(n)$. *Dostatečně velký násobek* funkce $g(n)$ **shora omezuje** funkci $f(n)$ *pro dostatečně velké $n$*.

#### Složitost Omega

**Složitost Omega** vyjadřuje **dolní hranici** časového chování algoritmu.
$$f(n) \in \Omega(g(n)) \Longleftrightarrow \exists c > 0, n_0 \in \mathbb{N}: \forall n \geq n_0, c \cdot g(n) \leq f(n)$$

Funkce $f(n)$ je **rostoucí minimálně tak rychle** jako funkce $g(n)$.

#### Složitost Theta

**Složitost Theta** vyjadřuje **třídu chování algoritmu** – ohraničení *z obou stran*.
$$f(n) \in \Theta(g(n)) \Longleftrightarrow \exists c_1 > 0, c_2 > 0, n_0 \in \mathbb{N}: c_1 \cdot g(n) \leq f(n) \leq c_2 \cdot g(n)$$

Funkce $f(n)$ **roste tak rychle** jako funkce $g(n)$. Jedná se o *nejpřesnější popis chování algoritmu* a není možné ji vždy přesně stanovit.

### Typické časové složitosti

| Složitost           | Název         |
| ------------------- | ------------- |
| $\Theta(1)$         | konstantní    |
| $\Theta(\log\ n)$   | logaritmická  |
| $\Theta(n)$         | lineární      |
| $\Theta(n\ log\ n)$ | linearitmická |
| $\Theta(n^2)$       | kvadratická   |
| $\Theta(n^3)$       | kubická       |
| $\Theta(n^k)$       | polynomiální  |
| $\Theta(k^n)$       | exponenciální |
| $\Theta(2^n)$       | binomická     |
| $\Theta(n!)$        | faktoriálová  |
