**Jazyk symbolických instrukcí** (*assembly language*) je *nízkoúrovňový programovací jazyk*, který obsahuje **symbolické reprezentace** jednotlivých *strojových instrukcí*.

**Assembler** je program, který slouží *k překladu jazyka symbolických instrukcí* do strojového kódu. **Strojový kód** je *specifický pro procesor* a jedná se o sekvenci instrukcí zapsaných jako *posloupnost číselných kódů* těchto instrukcí. Přeneseně se jako *assembler* označuje i jazyk symbolických instrukcí.

## Registry x86

Registry s prefixem `E` jsou **32bitové**, jinak **16bitové**. U obecných registrů lze navíc přistupovat k **horním** (`AH`) a **dolním** (`AL`) 8 bitům dolní poloviny.

![[41_registry.png]]

### Obecné registry

- **(E)AX** (*accumulator*) – střadač, matematické operace, obecné využití
- **(E)BX** (*base*) – základ efektivní adresy – ukazatel do paměti (v 16b režimu)
- **(E)CX** (*counter*) – čítač
- **(E)DX** (*data*) – data, nejvyšší významové slovo násobení a zbytek celočíselného dělení

### Indexové registry

- **(E)SP** (*stack pointer*) – ofset (ukazatel) vrcholu zásobníku
- **(E)BP** (*base pointer*) – bázový ofset (ukazatel) zásobníku (parametry funkcí)
- **(E)SI** (*source index*) – ofset (ukazatel) zdroje dat v paměti, indexování polí
- **(E)DI** (*destination index*) – ofset (ukazatel) cíle dat v paměti, indexování polí

### Segmentové registry

- **CS** (*code segment*) – kódový segment, ve spojení s instrukčním ukazatelem `(E)IP` ukazuje na následující instrukci
- **DS** (*data segment*) – implicitní datový segment, ve spojení s `(E)SI` a `(E)DI` ukazuje na proměnné
- **SS** (*stack segment*) – zásobníkový segment, ve spojení s `(E)SP` ukazuje na vrchol zásobníku a ve spojení s `(E)BP` ukazuje na jiné místo v zásobníku

### Příznakový registr (E)FLAGS

- **OF** (*overflow flag*) – přetečení při aritmetice se znaménkem
- **CF** (*carry flag*) – přetečení při aritmetice bez znaménka
- **SF** (*sign flag*) – znaménko výsledku (0 = kladný, 1 = záporný)
- **ZF** (*zero flag*) – výsledek roven nule (0 = různý od nuly, 1 = roven nule)
- **DF** (*direction flag*) – směr řetězových instrukcí (0 = nahoru, 1 = dolů)
- **PF** (*parity flag*) – příznak parity

## Volání funkcí

1. Volající **uloží na zásobník** parametry (podle konvence).
2. Volající použije instrukci `CALL` a **volaný přebírá řízení**.
3. Funkce s parametry vytvoří **zásobníkový rámec**.
4. Po skončení funkce je nutné **uklidit zásobník** (podle konvence).

### Zásobníkový rámec

1. Uložení původního stavu EBP.
2. Uložení vrcholu zásobníku ESP do EBP.
3. Rezervování místa na lokální data.
4. ????
5. Obnovení původního stavu zásobníku.

> [!note] Směr zásobníku
> Zásobník x86 „**roste dolů**“, proto se od ESP odečítá.

K **parametrům funkce** se pak přistupuje jako `[EBP + offset]`, k **lokálním proměnným** jako `[EBP + offset]`. **Výsledek funkce** se předává v registru AL, AX, EAX nebo EDX:EAX podle velikosti návratového typu, reálné číslo se vrací v FPU registru ST0.

```
funkce:
	PUSH EBP
	MOV EBP, ESP
	SUB ESP, local_data_size
	...
	MOV ESP, EBP
	POP EBP
	RET
```

### Konvence volání

| Konvence  | Parametry funkce | Zásobník uklízí | Dekorace jmen | Použito v |
| --------- | ---------------- | --------------- | ------------- | --------- |
| `pascal`  | zleva doprava    | volaný          | `symbol`      | Pascal    |
| `cdecl`   | zprava doleva    | volající        | `_symbol`     | C         |
| `stdcall` | zprava doleva    | volaný          | `_symbol@4`   | Win32 API |

#### Konvence pascal

```
; Parametry zleva doprava
PUSH parametr1
PUSH parametr2
...
PUSH parametrN
CALL funkce

funkce:
	PUSH EBP
	MOV EBP, ESP
	SUB ESP, local_data_size
	...
	MOV ESP, EBP
	POP EBP
	; Uklizi volany
	RET 4*N
```

#### Konvence cdecl

```
; Parametry zprava doleva
PUSH parametrN
...
PUSH parametr2
PUSH parametr1
CALL funkce
; Uklizi volajici
ADD ESP, 4*N

funkce:
	PUSH EBP
	MOV EBP, ESP
	SUB ESP, local_data_size
	...
	MOV ESP, EBP
	POP EBP
	
	RET
```

#### Konvence stdcall

```
; Parametry zprava doleva
PUSH parametrN
...
PUSH parametr2
PUSH parametr1
CALL funkce

funkce:
	PUSH EBP
	MOV EBP, ESP
	SUB ESP, local_data_size
	...
	MOV ESP, EBP

	; Uklizi volany
```
