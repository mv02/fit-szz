# Poznámky k SZZ

Manuálně psané poznámky k bakalářským státnicím na FIT VUT v Brně, 2025

## Použití

Psáno v poznámkovém editoru [Obsidian](https://obsidian.md/).
Stačí naklonovat a otevřít vault.

Pro větší přehlednost doporučuji použít theme, které barevně odlišuje tučný text a kurzívu (např. Catppuccin, který je přiložený v repu a nastavený jako default – barvy jde upravit přes Style Settings).

## Obsah

- Povídání k většině okruhů v Markdownu (včetně tabulek, barviček, LaTeXu, linků mezi tématy atd.)
- Prezentace a studijní opory, ze kterých se čerpá
- Obrázky

Některé části jsou nedokončené, některé okruhy jsou stručné nebo chybí úplně. Doplňující PRs jsou vítané.
